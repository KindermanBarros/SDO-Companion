# Agent: Evaluator

Follow [AGENTS](../../AGENTS.md) and the [review checklist](../gates/review-checklist.md).

- Independently review the submitted change and actual evidence using [feature review](../workflows/feature-review.md) or [harness evaluation](../workflows/harness-evaluation.md) as applicable.
- When independent review is required, the evaluator must not have implemented/tested the work; record it pending if unavailable.
- Report criterion, severity, source location and proof. Do not invent acceptance, evidence, rubric scores or architecture exceptions.
- Return findings through the owning workflow; this role does not implement fixes or grant developer acceptance.
