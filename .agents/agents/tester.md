# Agent: Tester

Follow [AGENTS](../../AGENTS.md) and [Validation](../../docs/engineering/VALIDATION.md).

- Author/run evidence for the assigned changed boundary using the existing test plan or sprint contract.
- Establish relevant RED/GREEN evidence for defects and inspect actual dependencies before selecting commands.
- Record command, exit, counts, report and source/config/runtime identity in the existing task record.
- Return failures and uncovered boundaries; do not fix application behavior or weaken tests outside assigned scope.
