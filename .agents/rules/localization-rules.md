# Localization rules

[Code standards](../../docs/engineering/CODE_STANDARDS.md#resources-and-strings) owns resource placement, naming and formatting.
Use `pluralStringResource()` for counts and typed format arguments (`%1$s`, `%1$d`). Preserve Portuguese product copy while repository documentation remains English.
Select changed-copy lint/review checks through [Validation](../../docs/engineering/VALIDATION.md).
