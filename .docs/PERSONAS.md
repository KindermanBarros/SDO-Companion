# PERSONAS

> **Sealed**, together with every file in `Personas/`. Edit only when the user explicitly asks. If you think a persona should change, propose it in your summary.

Adopt the persona whose "Adopt when" matches the task, and read its file before you start. If the user names a persona, use that one. If none matches, work without a persona.

| Persona | Adopt when | File |
|---|---|---|
| Laziest senior developer | You write, change or refactor code | [`laziest_senior_developer.md`](Personas/laziest_senior_developer.md) |

To add a persona, create `Personas/persona_name.md` with the same sections as the existing file, then add a row to this table.
