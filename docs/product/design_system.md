# SDO Companion design references

Status: adoption draft, pending approval. This document registers the existing design references for onboarding. It does not approve a redesign or certify visual compliance.

## Existing references

- [SDO Companion Design Guide](../../DESIGN_GUIDE.md): existing standard interface, semantic Material theme roles, responsive behavior and accessibility constraints.
- [Experimental Cybergrunge direction](../interface-cybergrunge.md): the existing alternate visual mode and its experimental constraints.
- [Cybergrunge implementation plan](../cybergrunge-implementation-plan.md): historical implementation guidance, not new authorization.

## Adoption boundary

Preserve both existing modes during onboarding. No visual, interaction, copy or accessibility behavior changes are proposed. Where the references or implementation differ, record the gap rather than selecting a replacement silently. Future UI work must resolve the intended behavior and reference precedence through create-ui-and-verify, including any explicit design-system exception and approved Pen targets.
